# Troubleshooting: Maven Wrapper Not Found in CI

## Problem

CI fails with error:
```
./mvnw: No such file or directory
Error: Process completed with exit code 127
```

## Root Cause

The Maven wrapper files (`mvnw`, `mvnw.cmd`, `.mvn/`) were not committed to the repository. This usually happens because:
1. They were added to `.gitignore` by mistake
2. They were never generated by Spring Initializr
3. They were accidentally deleted

## Solution

### Quick Fix

```bash
# 1. Navigate to project root
cd veteran-connection

# 2. Update .gitignore - REMOVE these lines:
#    backend/.mvn/
#    backend/mvnw
#    backend/mvnw.cmd

# 3. Force add Maven wrapper files
git add -f backend/mvnw
git add -f backend/mvnw.cmd
git add -f backend/.mvn/

# 4. Make wrapper executable
chmod +x backend/mvnw

# 5. Commit and push
git add .gitignore
git commit -m "fix: add Maven wrapper for CI/CD"
git push origin main
```

### If Maven Wrapper Files Don't Exist

#### Option 1: Using Maven (if installed locally)
```bash
cd backend
mvn wrapper:wrapper
git add mvnw mvnw.cmd .mvn/
git commit -m "chore: add Maven wrapper"
git push
```

#### Option 2: Manual Download
```bash
cd backend

# Download wrapper scripts
curl -o mvnw https://raw.githubusercontent.com/apache/maven/master/maven-wrapper/src/main/resources/mvnw
curl -o mvnw.cmd https://raw.githubusercontent.com/apache/maven/master/maven-wrapper/src/main/resources/mvnw.cmd

# Create .mvn directory structure
mkdir -p .mvn/wrapper

# Download wrapper jar and properties
curl -o .mvn/wrapper/maven-wrapper.jar https://repo.maven.apache.org/maven2/org/apache/maven/wrapper/maven-wrapper/3.2.0/maven-wrapper-3.2.0.jar
curl -o .mvn/wrapper/maven-wrapper.properties https://raw.githubusercontent.com/apache/maven/master/maven-wrapper/src/main/resources/.mvn/wrapper/maven-wrapper.properties

# Make executable
chmod +x mvnw

# Commit
git add mvnw mvnw.cmd .mvn/
git commit -m "chore: add Maven wrapper"
git push
```

#### Option 3: Regenerate from Spring Initializr
1. Go to https://start.spring.io
2. Configure with same settings as your project
3. Click "Generate" - downloads a zip
4. Extract and copy these files to your backend:
   - `mvnw`
   - `mvnw.cmd`
   - `.mvn/wrapper/maven-wrapper.jar`
   - `.mvn/wrapper/maven-wrapper.properties`
5. Commit and push

## Prevention

### Updated .gitignore

Your `.gitignore` should **NOT** contain:
```bash
# ❌ WRONG - Don't ignore Maven wrapper
backend/mvnw
backend/mvnw.cmd
backend/.mvn/
```

It should **ONLY** contain:
```bash
# ✅ CORRECT - Only ignore build artifacts and IDE files
backend/target/
backend/.idea/
backend/*.iml
```

### Why Maven Wrapper Should Be Committed

The Maven wrapper (`mvnw`) is essential because:
- ✅ **Portability**: Anyone can build without installing Maven
- ✅ **CI/CD**: GitHub Actions can build your project
- ✅ **Version Control**: Locks Maven version for consistency
- ✅ **Team Development**: Everyone uses same Maven version

### Files That Should Be Committed
```
backend/
├── .mvn/
│   └── wrapper/
│       ├── maven-wrapper.jar         # ✅ Commit
│       └── maven-wrapper.properties  # ✅ Commit
├── mvnw                               # ✅ Commit
├── mvnw.cmd                           # ✅ Commit
├── pom.xml                            # ✅ Commit
└── src/                               # ✅ Commit
```

### Files That Should Be Ignored
```
backend/
├── target/                            # ❌ Ignore (build output)
├── .idea/                             # ❌ Ignore (IDE files)
└── *.iml                              # ❌ Ignore (IDE files)
```

## Common Mistakes

### Mistake 1: Following Bad .gitignore Templates
Some online templates incorrectly suggest ignoring the Maven wrapper. Always review templates!

### Mistake 2: Using Global .gitignore
Don't add Maven wrapper to your global Git ignore file (`~/.gitignore_global`).

### Mistake 3: Assuming Maven Must Be Installed
The whole point of the wrapper is that Maven doesn't need to be installed locally!

## Related Issues

### Issue: mvnw has wrong line endings (Windows)
```bash
# Convert line endings
dos2unix backend/mvnw

# Or in Git
git add --renormalize backend/mvnw
```

### Issue: mvnw not executable
```bash
chmod +x backend/mvnw
git add backend/mvnw
git commit -m "fix: make mvnw executable"
```

### Issue: Maven wrapper version mismatch
Edit `backend/.mvn/wrapper/maven-wrapper.properties`:
```properties
distributionUrl=https://repo.maven.apache.org/maven2/org/apache/maven/apache-maven/3.9.6/apache-maven-3.9.6-bin.zip
```
